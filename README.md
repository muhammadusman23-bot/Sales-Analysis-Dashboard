📊 Sales Analysis Dashboard — Excel EDA Project
A fully self-contained sales analysis built in Microsoft Excel — from raw data to a polished, interactive dashboard — using Power Query, Power Pivot, and DAX.

🗂️ Project Summary
This project walks through the complete data analysis workflow: cleaning messy raw data, structuring it into a proper data model, computing business KPIs, and presenting everything through an interactive dashboard with real-time filtering.

🔧 What Was Built
Data Preparation — Power Query
Raw sales data was imported, cleaned, and reshaped before loading into the model.
Data Model — Power Pivot (Star Schema)
Three related tables were connected to form a clean analytical structure:

Orders — Fact Table
Customers — Dimension Table
Products — Dimension Table

KPI Calculations — DAX Measures

Total Revenue
Total Orders
Average Delivery Time
Average Customer Spend

Analysis — Pivot Tables

Monthly Revenue Trends
Day-wise & Hour-wise Sales Patterns
Revenue by Occasion and Category
Top Products and Top Cities by Orders

Visualization — Pivot Charts & Slicers
Dashboard built with bar, line, and combo charts. Slicer-based filtering enabled for Occasion, Order Date, and Delivery Date.

❓ Business Questions Addressed

Which products and categories contribute most to revenue?
How do sales fluctuate across months and days of the week?
Which occasions drive the strongest performance?
What is the typical order-to-delivery turnaround time?
Which cities generate the highest order volumes?
